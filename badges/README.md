# Achievement Badges

This directory contains achievement badges from external competitive programming platforms.

**Note**: These images are currently not referenced in the repository README or documentation. They are retained for historical record but are not actively used in the current repository structure.

## Contents

- **50 Days of Coding.png** - Coding streak achievement
- **100.png, 100.gif** - 100 problems solved milestones
- **7.png, 7.gif, 8.png, 8.gif, 9.png, 9.gif** - Daily streak badges
- **CodeChefBadge.png** - CodeChef achievement
- **LeetCode_75.gif** - LeetCode 75 problems
- **Top_Interview_150.gif** - LeetCode Top Interview 150
- **diamond.svg, diamond.avif** - CodeChef Diamond League
- **league-5.svg** - CodeChef League Level 5

## Purpose

These badges were previously used to display achievement progress. The repository now uses generated statistics and focuses on algorithmic knowledge rather than gamified badges.
