# Algorithmic Patterns

This directory contains focused documentation on common algorithmic problem-solving patterns for competitive programming and interview preparation.

Each pattern document explains:
- When to recognize the pattern
- Core idea and invariant
- Common complexity
- Common variations
- Common pitfalls
- Representative problems from this repository

## Available Patterns

- [Arrays](arrays.md) - Prefix sums, two pointers, array transformations
- [Two Pointers](two-pointers.md) - Opposite and same-direction pointer techniques
- [Sliding Window](sliding-window.md) - Fixed and variable-size windows
- [Binary Search](binary-search.md) - Standard search and binary search on answer
- [Greedy](greedy.md) - Exchange arguments, interval scheduling
- [Recursion and Backtracking](recursion-backtracking.md) - State space exploration
- [Trees](trees.md) - Tree traversal, diameter, LCA
- [Graphs](graphs.md) - BFS, DFS, shortest paths, MST
- [Dynamic Programming](dynamic-programming.md) - State design, transitions, optimization
- [Hashing](hashing.md) - Frequency counting, lookups, rolling hash

## How to Use

1. **Problem identification**: Match problem shape to pattern
2. **Pattern reference**: Read the pattern document for core idea
3. **Template usage**: Copy templates from [templates/](../templates/)
4. **Pitfall avoidance**: Review [notes/pitfalls/](../notes/pitfalls/) for common mistakes
