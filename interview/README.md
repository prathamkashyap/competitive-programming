# Interview Preparation

This section provides an interview-focused structure that reuses the repository's existing algorithmic knowledge without duplicating the entire solution collection.

## Purpose

This section is for:
- Systematic interview preparation
- Quick pattern recognition during interviews
- Curated problem selection for common interview topics
- Complexity reference for interview discussions

## How to Use

1. **DSA Roadmap**: Follow [dsa-roadmap.md](dsa-roadmap.md) for progressive practice
2. **Pattern Recognition**: Use [patterns.md](patterns.md) to identify techniques quickly
