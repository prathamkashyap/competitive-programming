## Interactive Dashboard

The [dashboard](dashboard/) provides:
- Live platform statistics from external accounts
- Searchable and filterable problem browser
- Random problem picker
- Mobile-friendly responsive design

**GitHub Pages URL:** https://prathamkashyap.github.io/competitive-programming/dashboard/

## Generated Files

All files in `generated/` are automatically regenerated by scripts:
- Run `python3 scripts/generate_stats.py` to update repository statistics
- Run `python3 scripts/external_stats.py` to update external platform statistics
- A GitHub Action runs daily to keep external stats fresh

Do not edit files in `generated/` manually - your changes will be overwritten.
