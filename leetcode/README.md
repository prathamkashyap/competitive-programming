## 🗺️ Topic Roadmap & Pattern Matrix

| Topic / Category | Difficulty Spread | Key Techniques & Concepts |
| :--- | :---: | :--- |
| **Arrays & Hashing** | Easy / Medium | Hash Maps, Hash Sets, Frequency Arrays, Prefix Products |
| **Two Pointers** | Easy / Medium | Opposite Ends, Fast & Slow Pointers, Dutch National Flag |
| **Sliding Window** | Medium / Hard | Fixed Window, Dynamic Window, Longest/Shortest Substring |
| **Stack & Monotonic Stack** | Medium / Hard | Next Greater Element, Daily Temperatures, Largest Histogram |

| **Trees & Binary Search Trees** | Medium / Hard | Tree Traversals (Inorder/Preorder/Postorder), LCA, Subtree Properties |
| **Tries (Prefix Trees)** | Medium / Hard | Word Dictionary, Autocomplete, Prefix Matching |
| **Heap / Priority Queue** | Medium / Hard | Top K Frequent Elements, Median from Data Stream, Task Scheduler |
| **Backtracking** | Medium / Hard | Subsets, Permutations, Combination Sum, N-Queens, Word Search |
| **Graphs** | Medium / Hard | BFS, DFS, Dijkstra, Kahn's Topological Sort, Island Problems |
| **1D & 2D Dynamic Programming** | Medium / Hard | Climbing Stairs, 0/1 Knapsack, Coin Change, LIS, LCS, Edit Distance |
| **Greedy** | Medium / Hard | Jump Game, Gas Station, Hand of Straights, Merge Intervals |
| **Intervals** | Medium / Hard | Non-overlapping Intervals, Meeting Rooms, Insert Interval |
