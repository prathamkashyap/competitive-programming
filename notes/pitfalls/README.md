# Common Pitfalls and Mistakes

This directory contains practical notes on common mistakes that cause WA, TLE, RE, or incorrect complexity assumptions in competitive programming.

These notes focus on actual implementation mistakes rather than theoretical concepts.

## Available Notes

- [Overflow and Integer Types](overflow-and-integer-types.md) - Integer overflow, type selection, negative modulo
- [Off-by-One Errors](off-by-one-errors.md) - Array indexing, loop conditions, prefix sums
- [Complexity Mistakes](complexity-mistakes.md) - Wrong complexity, hidden constants, optimization
- [Recursion and Stack Depth](recursion-and-stack-depth.md) - Stack overflow, infinite recursion, memoization
- [Graph Traversal Mistakes](graph-traversal-mistakes.md) - Parent tracking, disconnected graphs, initialization
- [Binary Search Invariants](binary-search-invariants.md) - Loop conditions, monotonicity, search bounds
- [DP State Definition](dp-state-definition.md) - State design, transitions, base cases, space optimization

## How to Use

1. **Before coding**: Review pitfalls relevant to your approach
2. **When debugging**: Check if your bug matches a known pitfall
3. **For review**: Use as a checklist of common mistakes
