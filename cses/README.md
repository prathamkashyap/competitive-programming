# 🇫🇮 CSES Problem Set Solutions

[![CSES](https://img.shields.io/badge/Platform-CSES-darkred?style=for-the-badge)](https://cses.fi/problemset/)
[![Language](https://img.shields.io/badge/Language-C++20-00599C?style=for-the-badge&logo=c%2B%2B)](https://github.com/prathamkashyap/competitive-programming)

Solutions and comprehensive breakdowns for the standard **CSES Problem Set** (by University of Helsinki / Antti Laaksonen). The CSES Problem Set is widely regarded as one of the best problem collections for mastering core algorithms and data structures.

---

## 📚 Section Breakdown & Progress

| Section | Topic | Problem Count | Focus Areas |
| :--- | :--- | :---: | :--- |
| **1. Introductory Problems** | Warm-up & Logic | 19 | Simulation, Recursion, Bitmasks, Grid Traversals |
| **2. Sorting and Searching** | Foundational Techniques | 35 | Binary Search, Two Pointers, Greedy, Custom Comparators |
| **3. Dynamic Programming** | Classical DP Patterns | 19 | 1D/2D DP, Coin Change, Knapsack, LIS, Grid Paths |
| **4. Graph Algorithms** | Graph Theory | 36 | BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, Kruskal |
| **5. Range Queries** | Advanced Data Structures | 19 | Fenwick Tree, Segment Tree, Lazy Propagation, Sparse Table |
| **6. Tree Algorithms** | Tree Properties | 16 | Tree Traversals, Diameter, Binary Lifting (LCA), Subtree DP |
| **7. Mathematics** | Number Theory & Combinatorics | 31 | Exponentiation, Modular Inverse, Prime Factoring, Matrix DP |
| **8. String Algorithms** | String Processing | 17 | Hashing, Trie, KMP, Z-Algorithm, Suffix Automaton |
| **9. Geometry** | Computational Geometry | 7 | Cross Products, Point Inclusion, Convex Hull |
| **10. Advanced Techniques** | High-Level CP Topics | 24 | Meet in the Middle, SQRT Decomposition, Mo's Algorithm |
| **11. Additional Problems** | Mixed Challenge | 77 | Hard & Non-standard Hybrid Challenges |
