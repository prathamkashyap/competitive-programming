# Assets

This directory contains purposeful visual assets for navigation and identity.

## Structure

### icons/
Lightweight SVG icons for semantic navigation:
- `cpp.svg` - C++ language icon
- `python.svg` - Python language icon
- `java.svg` - Java language icon
- `algorithms.svg` - Algorithms section
- `graphs.svg` - Graph algorithms
- `dp.svg` - Dynamic programming
- `templates.svg` - Templates section
- `notes.svg` - Notes section

These icons are minimal and functional, not decorative.

### banners/
Repository banner (optional, currently empty).

A single tasteful banner may be added here if needed for repository identity.

## Principles

- **Purposeful**: Every asset serves a navigation or semantic purpose
- **Minimal**: Avoid decorative complexity
- **Professional**: Engineering/CS identity, not gamified
- **Lightweight**: Prefer simple SVGs over large images
