## 💡 Key Focus: Educational DP Contest (EDPC)

The Educational DP Contest is an essential stepping stone for dynamic programming mastery:
- **A - Frog 1** (Basic 1D DP)
- **B - Frog 2** ($K$-step transitions)
- **C - Vacation** (State Machine DP)
- **D - Knapsack 1** (Standard 0/1 Knapsack with $W \le 10^5$)
- **E - Knapsack 2** (Value-based DP with $W \le 10^9$)
- **F - LCS** (Longest Common Subsequence reconstruction)
- **G - Longest Path** (DP on DAG)
- **H - Grid 1** (Grid Path Counting $\pmod{10^9+7}$)
- **I - Coins** (Probability DP)
- **L - Deque** (Game Theory / Minimax DP)
- **M - Candies** (Prefix Sum optimized DP)
- **O - Matching** (Bitmask DP)
- **P - Independent Set** (Tree DP)
