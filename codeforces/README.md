## ⚙️ Compilation

All solutions use C++20 and can be compiled with:

```bash
g++ -std=c++20 -O2 -Wall -Wextra solution.cpp -o solution
```

## 💡 Quick Tips

- Read problem statement carefully
- Check constraints before choosing algorithm
- Use fast I/O for large input
- Test with sample cases before submitting
